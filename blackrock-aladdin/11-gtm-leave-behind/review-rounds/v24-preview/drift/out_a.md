## Separate flags

**A. Facts in sentences 1 to 45 with no superscript and no other citation in the paragraph.** None. Every one of sentences 1 to 45 carries a superscript. Three nearby uncited statements that are not in CHANGED.md are worth a look:
- **Executive summary:** "It draws on about two thousand registered tools and agents, and each tool maps to an Aladdin API already in production." It is uncited because the ⟦9⟧ sits one sentence later on the negative claim (see item 1). "Copilot answers questions for staff and clients in about 100 Aladdin applications" is in the same position.
- **Executive summary:** "Each API has its own OAuth scopes, and most split read from write." The ⟦6⟧ later in the paragraph covers it, but the "most" needs care. Only 23 of the 54 specifications have both a :read and a :write scope. 12 are read only and 2 are write only. 17 have one undivided scope. So 37 of 54 use read or write scopes. If the author means "most have separate read and write scopes", that is false (23 of 54). A safer wording is "most mark each scope as read or write".
- **Exhibit 4 source line:** "The public SDK uses both names, Aladdin Compute and Studio Compute, for the same hosted environment." It has no superscript but sits in the source line beside the README (26). The SDK does use both: README line 179 says "Aladdin Studio Compute sessions" and fsutil.py says "Aladdin Compute sessions". No fix needed.

**B. Quotes whose ellipsis changes the meaning.**
- **B1. Sentence 35 (Goel, Exhibit 6).** "Every single transaction ... via an event, via an API". The ellipsis cuts "that happens should be available and accessible to you". The source states an aim, and the quote reads as a description of what exists. The second fragment, "a near real time data store", has the same problem without an ellipsis. It drops "we actually want to give you". Smallest fix: quote "every single transaction that happens should be available and accessible to you via an event, via an API" and "we actually want to give you a near real time data store".
- **B2. Exhibit 6 Woodhead row, outside my range.** I note it because it follows the same pattern. "The Aladdin data cloud built on top of Snowflake ... developer tools" cuts "And increasingly we're building a set of" before "developer tools". The "Parts they name" column then lists developer tools as an existing part. Suggested fix: end the quote with "And increasingly we're building a set of developer tools", as the block quote above it already does.

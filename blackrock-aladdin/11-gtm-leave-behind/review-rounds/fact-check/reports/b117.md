Recommended corrections:
- p15-101: Keep the 2. Optionally add a note that FactSet's MCP server (mcp.factset.com) needs FactSet OAuth credentials and an entitled data tier.
- p15-102: Change FactSet's Call to action from 0 to 1. developer.factset.com/contact offers a form "to get a free trial to our APIs", and the home page has Explore APIs, Explore MCP and Get Started buttons. All of these lead to approval or a corporate login. Also review FactSet's "Trial or sandbox: 0" (not in this batch) against the same free-trial form.

- p15-104: Change MSCI's API catalog from 0 to 2 (or 1 if gated specs count against it). developer.msci.com/apis lists 28 APIs publicly. Cite developer.msci.com, not source 4.
- p15-105: Keep the 0, but cite developer.msci.com (every API record has sandBoxEnabled false) rather than source 4.
- p15-106: Keep the 0, but cite developer.msci.com ("Get Access", where MSCI provisions the API key) rather than source 4.

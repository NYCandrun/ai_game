## Recommended corrections
- p13-05: No change needed. Optionally name "Arcesium Intelligence (May 2026)". Cite 57 for the platform and 56 for the Aquata features.
- p13-06: Replace "call these APIs every day" with wording the talk supports, for example "About 100 Aladdin applications, used by thousands of people every day, now embed Copilot 8".
- p13-07: Change "thousands of Copilot tools" to "a couple of thousand Copilot agents and tools, many mapped one-to-one to existing Aladdin APIs". Drop "every day".
- p13-08: Attribute only the Copilot tools and agents to the 50 to 60 teams, not the applications.
- p13-09: Change "under each user's permissions" to "on behalf of the user, with access set by user group and application". Drop "every day".
- p13-10: Optionally change to "Orders posted through the API are checked for compliance by default (runCompliance defaults to true)", citing 6 only for this clause.

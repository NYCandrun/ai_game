- p15-29: Change Bloomberg's AI connector score from 0 to 2, citing Bloomberg Enterprise MCP (press release Sept 29, 2026; DL+ product page). At minimum it is 1. This also undercuts the "Investment platforms cluster low" narrative for AI access, and it should be reconciled with the p11 claim that Bloomberg has no AI announcement (see b078).
- p15-30: Define the "Call to action" scale in the footnote. Then rescore Bloomberg consistently with Studio. If "Request a Demo" or "Book a meeting" scores 0, Bloomberg drops to 0. If an open SDK download counts, say so.
- p15-31: Add sources 23 and 24 to Exhibit 17's source line for the Studio row. Source 14 alone does not show any public documentation.
- p15-32: Add sources 6 and 23 (PyPI plugin packages and README plugin list) to the source line. Source 14 has no catalog.
- p15-33: No change. Optionally add 23 as the source.

Executive summary

Clients’ AI tools could act on Aladdin under the same controls BlackRock’s own business runs on.

Studio is Aladdin’s developer and data layer: APIs and events, Aladdin Data Cloud on Snowflake, and developer tools1. Many data providers now offer AI tools a way to read their data2, 3, 4, 5. Aladdin’s APIs also change the book. They post orders and set compliance rules, under each user’s permissions and with a compliance check on every order6.

Letting AI tools act will not stay unique; SimCorp has announced AI agents7. What BlackRock can show is its own use. About 100 of its applications and thousands of Copilot tools already call these APIs every day8. Buyers say AI is changing what they build, and BlackRock has told investors that API calls will grow 17x by 20309, 10. Part 3 sets out this direction, what would have to be true for it to hold, and four pieces of marketing work that would follow.

Part 1What the public record shows

Aladdin is the investment platform BlackRock built for itself and sells to other institutions. Brennan Rosales, its AI Engineering Lead, put the scale this way at a LangChain conference in 2025. “BlackRock is the biggest user of Aladdin, but we also sell and support hundreds of clients globally across 70 countries.” The organization is “around 7,000 people, with over 4,000 of those being engineers.” They maintain “around 100 Aladdin front-end applications”8. BlackRock’s technology services and subscription revenue was $2.0 billion in 2025, up 24 percent including Preqin, the private-markets data firm bought in 202511. BlackRock sells the platform as one engine with separate entry points, and Studio is the entry point for people who write code.

What BlackRock sells

Exhibit 2 follows one trade through Aladdin, step by step, as far as the 54 public specifications describe it6, 20.

The specifications say more than Exhibit 5’s counts: they show how the APIs behave. Posting an order takes whatIf and runCompliance, which defaults to true, and the response returns any compliance violations inline6. Ten specifications expose an endpoint for long-running operations, 35 operations are flagged as long-running, and the SDK polls them23. Risk exceptions and Data Cloud datasets carry bitemporal fields, which record two time dimensions. Rule assignments and dataset releases name a four-eyes approval, a second sign-off6. Every request carries an application key plus OAuth 2.0 scopes such as trading.order_management.order.v1.Order:read, and the client ID and secret come from the Studio UI23.

What Studio is

Five BlackRock speakers define Studio in the 128 recordings I pulled for this document28, 29; Exhibit 6 lists each with the title the recording gives. BlackRock’s own definition comes from the head of Studio engineering, on Snowflake’s podcast in November 2025.

“So we think about Aladdin today as a platform and Aladdin Studio is essentially the user experience that allows people to think of Aladdin as a platform. It exposes everything Aladdin knows how to do as a set of APIs events. The Aladdin data cloud built on top of Snowflake takes all of that information that’s generated through our analytics factory and inside of Aladdin and pushes that into Snowflake. And increasingly we’re building a set of developer tools.”

— Dave Woodhead, Managing Director and Head of Engineering for Aladdin Studio, Snowflake Data Cloud podcast, published November 11, 20251

Four of the five describe Studio in the same terms, APIs and events plus the Data Cloud, and two of those four add developer tools. Newman calls Data Cloud “part of Studio”16. Goel describes events, APIs and a near-real-time data store26. Khara calls it programmatic access to data and reporting30. A 2026 job posting calls Studio “Aladdin’s extensibility layer”32. The message is consistent across speakers and years, so BlackRock already has a positioning for Studio.

Part 21. The public record of clients using Aladdin can serve as Studio’s proof

BlackRock’s Studio page names no client building on Studio14, and a full-text search of SEC EDGAR finds no filing that mentions Studio33. Proof that clients use Aladdin, though, is public. On BlackRock’s video, Royal London’s chief executive credits Aladdin’s Snowflake implementation34. JPMorgan Chase’s proxy statements report Aladdin payments of $4.4 million to $7.6 million a year from 2017 to 2023, then $14.7 million in 2024 and $25.6 million in 202535, 36.

A second kind of record is code written by a client’s engineers. In December 2025 an engineer at a client firm submitted two changes to the open-source SDK: URL rewriting and custom headers. Both are for firms that route Aladdin calls through an enterprise gateway. The BlackRock engineer who co-wrote the SDK’s launch post merged them38, 39, 40, 41. Janus Henderson’s 10-K says that in the third quarter of 2025 the firm chose to move its investment management system to Aladdin, “a complex, multi-year initiative”42. Public buyers add a third kind of record: procurement notices.

None of this proof names Studio, which matters less than it seems. Studio is sold for building custom applications on Aladdin, so a buyer wants to know that another institution built on the platform and stayed. Proof from one firm counts even when the buyer is a different kind of firm. Public pension funds, and firms whose filings or tenders already name BlackRock, are easier to name in public. So they are the natural first candidates for a named Studio story.

What this finding suggests about direction. A named Studio story can start with clients whose Aladdin use is already on the record.

2. BlackRock’s growth story to investors runs through Studio, though it rarely says the name

BlackRock tells investors growth will come from API calls, without naming the product behind them. It projected at its 2025 Investor Day that API calls across BlackRock and Aladdin would grow 17x by 203010. Attributing them to Studio is my inference10. I make that inference because API use is the activity the Studio page describes14. No executive said “Studio” on any of the 26 earnings calls from the first quarter of 2020 to the second quarter of 202646. Outside the calls, the only investor-facing mention I found is a single line on a 2023 Investor Day slide47. BlackRock’s 10-K says technology services fees are generally set by the value of positions on the platform or at a fixed rate. They can also depend on subscriptions, go-lives and support. The 10-K does not list API calls among the fee terms it names10, 11.

The private-markets data BlackRock has been adding reaches clients through Data Cloud and Explore. BlackRock bought eFront in 2019 and Preqin in 2025. In September 2025 its private markets team described the result on a client webinar52. Investors “now have access to over 15,000 fund investments within eFront Insight” for benchmarking. Preqin indices “are also available today in Aladdin Explore and our Aladdin Data Cloud capabilities”. And “over 10 different transaction types” were added to Aladdin, covering commitments, fundings, paydowns and PIK, so private credit loans are captured natively. The team said those were designed with BlackRock’s own professionals and “our new colleagues from HPS”52. Private credit analytics on Preqin followed in May 202613. Newman, the Studio general manager, names eFront data and Preqin among the data being added to Data Cloud16.

What this finding suggests about direction. BlackRock itself says growth will come from API calls, the fastest-growing measure it showed investors. The data it is adding, private markets and Preqin, arrives through Data Cloud and Explore. Both are Studio surfaces.

3. Aladdin’s AI answers inside the login; data providers let outside AI tools reach their data

Aladdin Copilot, the AI inside the login, is built on the same APIs Studio exposes. It draws on a registry of plugins, “couple of thousands agents and tools,” built by Aladdin’s engineering teams. The first way a team adds a tool is “to define a tool as kind of mapping one-to-one to an existing Aladdin API already out in production”8. So Copilot’s tools are Studio’s APIs. Microsoft’s Adrian Crockett made the dependence plain on BlackRock’s podcast: “There’s no copilot without plug-ins”53. On the data side, BlackRock’s AI product head says the team is making sure “the data model itself is structured for agentic use cases”54.

Exhibit 12 lists what the providers a Studio buyer compares have made public about AI access. Six data and cloud providers that Studio buyers also use offer a connector or an MCP server, and two system-of-record rivals have announced AI features. LSEG had 90 customers connected by April 2026, according to a secondary summary of its results slides2, 55.

What this finding suggests about direction. A public account of the Copilot plugin model would cover production Aladdin APIs, the same ones Studio exposes, each user’s own permissions, and tested no-advice guardrails8, 17. That account answers three governance questions: who can call what, with which permissions, and under which guardrails.

4. Buyers at BlackRock’s own webinar said they want a core platform plus their own builds

BlackRock ran a Build vs. Buy webinar for asset managers and polled the attendees. The first poll asked where firms sit today. 37 percent said they run “mostly vendor platforms,” 30 percent run a “hybrid,” 18 percent are “actively reevaluating,” and 15 percent are “mostly built in house”9. The second poll asked what is driving the build-or-buy decision. “AI and data demands” led at 42 percent; cost and speed to market tied for second9. The third poll asked what they would stop maintaining in house. 53 percent chose compliance reporting9.

“What’s the API suite that you have? Are you using connectors to Snowflake or to Databricks? And I think that that part of the RFP has become much more prominent.”

— Clark Schafer, Partner, Alpha FMC, on the Build vs. Buy webinar9

Alisha Sewdass, BlackRock’s Head of Aladdin Solutions Engineering, Americas, gave BlackRock’s side on the same webinar. She described the shift of the last two years. It is “to more of a modular approach where clients are looking for that backbone foundational data that supports both publics and privates workflows.” That comes, she said, with “very, very robust APIs that manage the end to end life cycle of a transaction.” Those APIs let clients build “their secret sauce rebalancing tools” on top9. On AI, she said, “you need that system of record that underpins anything that AI is built upon.” She also said “the other layer that is almost equally important is a really defined system of work”9.

Rivals are selling to the same buyer, the one who wants a core platform plus their own builds. SimCorp announced wins at AllianceBernstein in February 2026 and Pictet in May 2026. AllianceBernstein keeps its “specialized in-house technology,” and Pictet connects its own tools to SimCorp One by API61, 62. BlackRock’s own August 2026 insight page says the same: “Build vs buy is no longer a binary question”63.

What this finding suggests about direction. Buyers now ask in RFPs whether they can build on the platform. Studio is the right kind of answer.

Part 3Directions to explore

The findings suggest that Studio could be presented as the place where a client’s own AI tools act on investment data under the same controls BlackRock’s own business runs on. BlackRock has said parts of this. It sells Aladdin as the system it runs internally8, 14, 17, 19. Its speakers have said that the system of record underpins anything built with AI9, and that the data model is being structured for agentic use54. I have not found it describe Studio this way.

Letting AI tools act is unlikely to stay unique. SimCorp has announced AI agents, Arcesium an AI platform, and other systems of record will likely follow7, 56, 57. What BlackRock can show is its own use. About 100 of its applications and thousands of Copilot tools, built by 50 to 60 of its teams, call these APIs every day under each user’s permissions8. Every order is checked for compliance by default, and Copilot’s guardrails are tested daily6, 8. A client’s AI tools would work under controls BlackRock already relies on for its own business. How those tools would connect is not public60.

Buyers say AI is changing what they build. “AI and data demands” led BlackRock’s webinar poll at 42 percent as the reason firms are rethinking what to build and what to buy, and buyers now ask about APIs and connectors in RFPs9. The poll did not ask whether clients want AI tools that act on Aladdin, and it gives no sample size.

The client base is large. BlackRock serves hundreds of Aladdin clients in 70 countries8, and its technology services revenue was $2.0 billion in 202511. A 2026 job posting for Aladdin Graph, the team behind the API layer, says it builds for BlackRock and over 200 institutions that rely on its technology64. BlackRock sizes Aladdin’s addressable market at more than $20 billion10. It projects API calls to grow 17x by 2030, and AI tools acting for clients could become a large source of them10. Linking that figure to Studio is my inference. How many of those institutions run their own AI tools is not public.

Three things would have to be true for this direction to hold. Clients would have to want AI tools that act, not only ones that answer questions. Their risk teams and regulators would have to accept it, which likely means a person approves each action. And BlackRock would have to open its controls to tools it did not build.

Part 4What I could not see

Everything here was read from outside, which limits what this document can be sure of. Exhibit 16 follows a prospect’s engineer through six steps, from first hearing about Studio to getting help. For each step it records what is public today and what a client receives after qualification. I could read the pages, unpack the specifications and read the SDK’s code. I could not run anything, open the catalog, guides, notebooks or samples, or test what a client receives; where this document describes those, it relies on what sources say.

The SDK is the one piece of Studio a prospect can install before any conversation. Its README documents three run modes: “a developer’s local machine,” “Aladdin Studio Compute sessions” and a test mode. It stores a prompted password in the operating system’s credential manager. It carries settings for firms that consume “the Aladdin APIs via an enterprise API management platform such as Azure API Management”23.

Exhibit 17 puts Studio beside 10 platforms that a Studio buyer also deals with67, 68, 69. It scores each on eight things a developer with no client relationship can reach: 2 where the vendor opens it before any sale, 0 where access follows a relationship. The pattern is each vendor’s selling model. Investment platforms cluster low because they gate. At Aladdin, as at Bloomberg, State Street, SimCorp, Clearwater and Arcesium, documentation, a sandbox and a first call come after a relationship exists. Data and cloud platforms sell to developers directly and cluster high.

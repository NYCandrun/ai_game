Part 3

Directions to explore

The findings suggest that Studio could be presented as a way for a client to read its Aladdin data anywhere and act on it through the same APIs and controls BlackRock’s own applications use. Data Cloud puts the data in the client’s Snowflake account for analysis. Anything that changes the book, such as an order or a compliance rule, goes through the APIs, where user permissions apply and orders are checked for compliance by default. This is my reading of the specifications; BlackRock has not described Studio this way.11, 13

Buyers now ask about APIs and data connectors in RFPs. SimCorp also invites clients to build on its platform. BlackRock may be able to show something SimCorp cannot: a large investment business that runs on these APIs every day.2, 3, 61, 62

BlackRock told investors that API calls would grow 17x by 2030. If that growth comes from Studio, it likely depends on analysts and portfolio managers who write code using it daily, not only on the engineers who evaluate it. Linking that figure to Studio is my inference.7, 40

Clients will expect their own AI tools to reach Aladdin, as they already reach FactSet, LSEG and Snowflake.55, 51, 58 Copilot shows how that can work under each user’s permissions and with guardrails.3, 10 How a client’s own tools would connect is not public.60

Proof that clients use Aladdin is already public: JPMorgan Chase’s payment records, pension tenders, and client engineers contributing to the SDK. A named Studio story could start with one of them.29, 32, 33, 37, 38, 39

# Interactive field guide

`aladdin_field_guide.html` is a single-file interactive explainer: open it in any browser. Eleven lessons move from what Aladdin is, through the investment lifecycle, the 11 API domains, the architecture, request conventions, products, AI, and a glossary. Diagrams are clickable.

Published copy: https://claude.ai/artifact/SmPi1sZLYJ54QFn7Cwofca

`aladdin_field_guide_print.pdf` prints every lesson in sequence. `claims_checked.md` lists the factual claims on the page and how each was verified against the specs and transcripts (version 3 incorporated 31 corrections).

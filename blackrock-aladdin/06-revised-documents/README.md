# Revised documents

Each subfolder holds one document in five forms:

| File | What it is |
|---|---|
| `*.md` | The corrected text, source of truth for the plain editions |
| `*.docx` | Word edition (pandoc) |
| `*_plain.pdf` | PDF of the Word edition (LibreOffice) |
| `*.html` | BlackRock-styled print edition, following the samples in `07-design-references/` |
| `*.pdf` (no suffix) | PDF of the styled edition, rendered with Chromium. This is the final version. |

Both documents end with a "Verification notes" section listing every change made after the fact-check and what could not be checked.

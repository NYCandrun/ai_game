# Review rounds

Each folder is one round of review or production, named by its start time (UTC). The reports are the reviewers' own hand-backs, unedited; the first line of each file records when that reviewer started and finished.

1. `2026-10-19_0411_expert-panel-review-of-field-guide/`: four reviews of the first draft of the interactive guide (readability for an outsider, UI/UX interaction, visual design, copy), with before and after screenshots.
2. `2026-10-19_0601_media-crawl-and-audio-fetch/`: how the BlackRock media library and podcast feeds were crawled and how blocked YouTube audio was obtained.
3. `2026-10-19_1341_field-guide-fact-check/`: five reviewers checked the guide's claims against the transcript corpus; `claims_checked.md` is the list they worked from.
4. `2026-10-19_1403_document-fact-check/`: five reviewers checked the Briefing and What It Does V7.
5. `2026-10-19_1425_document-corrections/`: change logs for the corrected documents.
6. `2026-10-19_1447_branded-html-editions/`: build reports for the HTML editions, including the footnote fitting and page-number work.
